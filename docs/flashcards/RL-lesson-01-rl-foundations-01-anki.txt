What is the agent in reinforcement learning?	The <b>agent</b> is the decision maker: it chooses actions.	agent
What is the environment in reinforcement learning?	The <b>environment</b> is the system the agent interacts with: it responds to those actions and provides feedback.	environment
What is sequential decision making?	One decision changes the situation in which the next decision happens. RL often involves rewards that arrive only after several actions, so the learner must work out which earlier decisions helped.	sequential_decision_making
How does reinforcement learning differ from supervised learning?	In <b>supervised learning</b>, a training example usually includes a target answer, such as “this picture shows a cat.” In <b>RL</b>, feedback usually says how an outcome scored, without giving the best action as a label.<br><br>An RL agent also affects what it gets to observe: visiting the charger teaches it different things from cleaning another room.	supervised_learning_vs_RL
What happens at each step of the RL interaction loop?	The agent receives information describing the current <b>state</b> and chooses an <b>action</b> from the available choices. In response, the environment produces a <b>next state</b> and a <b>reward</b>.<br>\[S_t\rightarrow A_t\rightarrow(R_{t+1},S_{t+1}).\]<br>The reward is numbered \(t+1\) because it results from action \(A_t\).	interaction_loop
What is a transition, and how is it recorded?	A <b>transition</b> is one interaction step: the agent chooses an action in the current state, and the environment produces a reward and the next state.<br>We record it as \((S_t,A_t,R_{t+1},S_{t+1})\).	transition
What is a trajectory, and how is it written?	A <b>trajectory</b>, written \(\tau\), is a sequence of connected transitions: each transition’s next state becomes the following transition’s current state. It can describe a finite segment, a complete episode, or an ongoing sequence.<br>\[\tau=(S_0,A_0,R_1,S_1,A_1,R_2,\ldots).\]	trajectory
What is a policy?	A <b>policy</b>, written \(\pi\), tells the agent how to choose in each state.<br><br>“Charge whenever battery is low” is a <b>deterministic policy</b>: it specifies one action.	policy
What is a stochastic policy, and what does its notation mean?	A <b>stochastic policy</b> gives probabilities instead of specifying one action.<br>\[\pi(a\mid s)=P(A_t=a\mid S_t=s).\]<br>The chance of selecting action \(a\), given state \(s\). The available action probabilities must add to one.	stochastic_policy
What is a Markov Decision Process (MDP), and what is its defining requirement?	A <b>Markov Decision Process (MDP)</b> is a mathematical model of the agent–environment interaction. It specifies the possible states, the actions available in each state, the probabilities of transitions, and how rewards are generated.<br><br>Its defining requirement is the <b>Markov property</b>: the current state and chosen action contain enough information to determine the probabilities of the next state and reward.<br><br>Its ingredients are \((\mathcal S,\mathcal A,P,R,\gamma)\): states, actions, transition probabilities, reward rule or distribution, and discount factor.	MDP
What is an episode, and what happens at a terminal state?	An <b>episode</b> is an interaction sequence with a task-defined end, such as reaching an exit or failing.<br><br>In an episodic task, entering a <b>terminal state</b> ends the episode: no actions or rewards follow. Any success or failure reward belongs to the transition entering that state.	episode
What is truncation, and how does it differ from a genuine task deadline?	Stopping an experiment after 100 steps is <b>truncation</b> if the actual task would continue. It stops our record, not the underlying consequences.<br><br>A genuine task deadline is different: time remaining must be included in the state if it changes the best decision.	truncation
What is a bound? If rewards have magnitude at most M, what bounds the infinite discounted return?	A <b>bound</b> is a worst-case limit, not a prediction of the exact result.<br><br>If \(|R_t|\leq M\) and \(0\leq\gamma&lt;1\), their weighted magnitudes fit under the geometric sum:<br>\[|G_0|\leq\frac{M}{1-\gamma}.\]<br>For example, \(M=2\) and \(\gamma=0.5\) give a total-magnitude bound of \(4\).	bound
What is a reward?	A <b>reward</b> is a numerical signal that scores the resulting transition; it does not directly tell the agent which action was best.<br><br>A reward scores one transition.	reward
What is a return, and how is it calculated for an episode ending at decision time T?	A <b>return</b>, \(G_t\), combines the rewards from decision \(t\) onward. It is what we use to compare entire futures.<br>\[G_t=\sum_{k=0}^{T-t-1}\gamma^kR_{t+k+1}=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots.\]<br>We give the first reward weight one, including when \(\gamma=0\).	return
What does the discount factor control, and what happens at gamma = 0, between 0 and 1, and at gamma = 1?	The <b>discount factor</b>, \(\gamma\in[0,1]\), controls how much weight future rewards receive.<br><br>When \(\gamma=0\), only the next reward counts.<br>For \(0&lt;\gamma&lt;1\), rewards further in the future receive progressively less weight.<br>When \(\gamma=1\), all rewards receive equal weight.<br><br>We choose \(\gamma\) as part of the objective.	discount_factor
What is expected return?	When outcomes are random, compare <b>expected return</b>: a probability-weighted average over possible futures.<br><br>A one-step action paying \(10\) with probability \(0.8\) and \(-10\) with probability \(0.2\) has expected return \(0.8(10)+0.2(-10)=6\). It does not pay \(6\) on any single attempt, and this average alone does not describe its risk.	expected_return
