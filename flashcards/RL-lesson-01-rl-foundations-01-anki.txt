What is the agent in RL?	The decision maker: it chooses the actions.	agent
What is the environment in RL?	The system the agent interacts with: it responds to each action with a next state and a reward.	environment
What makes a problem sequential decision making?	Each decision changes the situation in which the next decision is made, so consequences (and rewards) can arrive several actions later.	sequential_decision_making
What feedback does supervised learning give that RL usually does not?	The correct answer as a label. RL feedback only scores how an outcome went; it does not say which action would have been best.	supervised_learning_vs_RL
Besides the type of feedback, what else makes RL data different from supervised data?	The agent's own actions decide which situations it gets to observe, so what it learns depends on how it behaves.	supervised_learning_vs_RL
What happens in one step of the RL interaction loop?	The agent sees state \(S_t\) and picks action \(A_t\); the environment returns reward \(R_{t+1}\) and next state \(S_{t+1}\).	interaction_loop
Why is the reward after action \(A_t\) written \(R_{t+1}\) and not \(R_t\)?	It is produced by the environment in response to \(A_t\), together with the next state \(S_{t+1}\). At decision 0 the agent sees \(S_0\), picks \(A_0\), then gets \(R_1\) and \(S_1\).	notation interaction_loop
How is a single transition written?	\((S_t,A_t,R_{t+1},S_{t+1})\): state, action, the reward it produced, next state.	transition notation
What is a trajectory \(\tau\)?	A sequence of connected transitions, where each next state is the following transition's current state:<br>\[\tau=(S_0,A_0,R_1,S_1,A_1,R_2,\ldots).\]	trajectory
How many transitions are in the trajectory “low battery, charge, −1, high battery, clean, +3, low battery”?	Two. Each transition is one (state, action, reward, next state) group, and the middle state is shared.	trajectory practice
What is a policy \(\pi\)?	A rule that tells the agent how to choose an action in each state.	policy
What is the difference between a deterministic and a stochastic policy?	A deterministic policy picks exactly one action per state. A stochastic policy gives a probability for each action.	policy stochastic_policy
Read \(\pi(a\mid s)\) in words.	The probability that the policy chooses action \(a\), given that the state is \(s\): \(P(A_t=a\mid S_t=s)\).	stochastic_policy notation
A policy has \(\pi(\text{charge}\mid\text{low})=0.8\). What must \(\pi(\text{clean}\mid\text{low})\) be if those are the only two actions?	\(0.2\). Action probabilities in each state must sum to one.	stochastic_policy practice
Can one deterministic policy produce different trajectories?	Yes. The policy's choices are fixed, but the environment's responses can be random.	policy trajectory
What is a Markov Decision Process (MDP)?	A mathematical model of the agent–environment interaction: the states, the actions, the transition probabilities and how rewards are generated.	MDP
What does each ingredient of \((\mathcal S,\mathcal A,P,R,\gamma)\) stand for?	States, actions, transition probabilities \(P(s'\mid s,a)\), reward rule, discount factor.	MDP notation
What does \(P(s'\mid s,a)\) mean?	The probability of landing in next state \(s'\) after taking action \(a\) in state \(s\).	MDP notation
What is the Markov property?	The current state and action are enough to give the probabilities of the next state and reward; earlier history adds nothing.<br>\[P(S_{t+1}\mid S_t,A_t,S_{t-1},\ldots)=P(S_{t+1}\mid S_t,A_t).\]	markov_property
Does the Markov property mean the next state is predictable with certainty?	No. The next outcome can be random; only its probabilities must depend on the current state and action alone.	markov_property
A robot's state is only its room. Why is that not a Markov state, and how do you fix it?	Cleaning risk depends on battery level, which the room does not show. Add battery level to the state.	markov_property practice
An enemy attacks every third turn. What must the state include to be Markov?	The turn count modulo 3 (the attack phase); HP alone does not tell you whether the next attack is due.	markov_property practice
What is the difference between an episodic and a continuing task?	An episodic task has a task-defined end (an exit, a failure). A continuing task has no natural end, e.g. managing heating indefinitely.	episode continuing_task
What happens when an agent enters a terminal state?	The episode ends: no further actions or rewards. Any success or failure reward belongs to the transition entering that state.	episode terminal_state
What is truncation?	Stopping the record of a task that would actually continue, e.g. ending a simulation after 100 steps. It cuts off our data, not the real consequences.	truncation
When must remaining time be part of the state?	When the task has a genuine deadline and the time left changes which action is best.	truncation markov_property
What is a reward?	A number scoring one transition. It does not say which action would have been best.	reward
What is the return \(G_t\)?	The (discounted) sum of rewards from decision \(t\) onward:<br>\[G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots\]	return
What is the difference between reward and return?	A reward scores one transition; the return combines all rewards from a point onward, so it scores an entire future.	reward return
Rewards \(-1,-1,+10\) with \(\gamma=0.9\). What is \(G_0\)?	\(-1+0.9(-1)+0.81(10)=6.2\)	return practice
Rewards \(-1,-1,+10\) with \(\gamma=0.9\). What is \(G_1\)?	\(-1+0.9(10)=8\). The discount exponents restart from the evaluation point.	return practice
What does the discount factor \(\gamma\) control?	How much weight future rewards get relative to the next reward, with \(\gamma\in[0,1]\).	discount_factor
What does \(\gamma=0\) mean for the return?	Only the next reward counts: \(G_t=R_{t+1}\).	discount_factor
What does \(\gamma=1\) mean for the return?	Every reward gets equal weight: the return is the plain sum.	discount_factor
Why can an infinite continuing task need \(\gamma&lt;1\)?	With bounded rewards and \(\gamma&lt;1\), the weights shrink and the sum stays finite. With \(\gamma=1\) it can grow without bound.	discount_factor bound
A reward of 1 forever with \(\gamma=0.9\). What is the return?	\(1/(1-0.9)=10\)	discount_factor practice
If \(|R_t|\leq M\) and \(0\leq\gamma&lt;1\), what bounds \(|G_0|\)?	\[|G_0|\leq\frac{M}{1-\gamma}\]This is a worst-case limit, not a prediction.	bound
What is expected return?	The probability-weighted average return over the possible futures. It is used to compare choices when outcomes are random.	expected_return
An action pays \(10\) with probability 0.8 and \(-10\) with probability 0.2. What is its expected return?	\(0.8(10)+0.2(-10)=6\). No single attempt pays 6, and the average alone hides the risk.	expected_return practice
A courier gets +1 for every move. What behaviour can that reward rule cause?	Wandering. The agent maximises the reward you wrote, so a per-move bonus rewards long routes. A move cost plus a delivery reward favours finishing.	reward_design
